# Faturamento

Em **Facturación** você configura o necessário para emitir faturas eletrônicas válidas perante a DIAN: resolução, dados fiscais, impostos e provedor técnico.

## Como acessar

Menu lateral → **Facturación**. Você verá um banner de readiness e cartões para completar a configuração.

## O que revisar

- **Resolución DIAN** — faixa autorizada e vigência
- **Datos fiscales** — identidade do negócio
- **Impuestos aplicados a ventas** — sob o guardrail do WARO
- **Proveedor técnico** — emissão eletrônica
- **Bitácora de números quemados** — controle de consecutivos
