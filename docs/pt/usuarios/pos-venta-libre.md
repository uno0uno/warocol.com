# Venda livre

**Venta libre** permite cobrar um valor em pesos que não está fixado no cardápio (serviços, encargos diversos). O caixa informa o valor na hora; não é preciso criar um produto novo a cada venda.

> O botão só aparece no POS se um administrador o ativar em **Operaciones → Personalizar**.

## Como acessar

1. Ative **Venta libre en POS** em **Operaciones → Personalizar**.
2. No POS, use o botão **Venta libre** no painel do carrinho.
3. Informe o valor (obrigatório) e, se quiser, uma descrição; depois cobre com o fluxo normal.
