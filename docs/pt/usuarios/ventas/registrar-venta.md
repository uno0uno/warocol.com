# Registrar venda manual

Use esta opção quando uma venda ocorreu fora do POS: pagamento antecipado, pedido por telefone, cortesia registrada depois, etc.

## Quando usar

- O cliente pagou antes de chegar ao local
- A venda foi processada em papel e precisa ser inserida no sistema
- Você precisa registrar uma venda em uma data passada

---

## Passos

### 1. Data, método de pagamento e cliente

- Selecione a **data** em que a venda ocorreu (não pode ser uma data futura)
- Escolha o **método de pagamento**. A lista usa os métodos configurados para o POS
- Se o método tiver submétodos (por exemplo Nequi ou Daviplata), selecione-o dentro do grupo correspondente
- Opcionalmente toque em **Identificar cliente** para associar a venda a um cliente registrado

Se você identificar um cliente com saldo na **wallet COP**, a wallet aparece como método de pagamento disponível. Se a venda ficar anônima ou o cliente não tiver saldo, esse método não é exibido.

### 2. Adicionar produtos

O catálogo mostra todos os seus produtos disponíveis.

- Toque em um produto para adicioná-lo ao carrinho
- Se o produto tiver **Modificadores**, aparece um painel lateral para selecioná-los
- Use os botões **+** / **−** para ajustar quantidades diretamente no carrinho

### 3. Confirmar

O painel direito (desktop) ou o resumo inferior (mobile) mostra o total em tempo real.

Pressione **Registrar** para salvar. A venda ficará registrada com a data que você escolheu e o estoque é descontado automaticamente se os produtos tiverem receitas configuradas.

---

## Perguntas frequentes

**O estoque é descontado?**
Sim, igual ao POS. Se o produto tiver uma receita, os itens de estoque são descontados ao registrar.

**Posso registrar uma venda sem identificar o cliente?**
Sim, o cliente é opcional em vendas manuais.

**Posso usar uma data de vários dias atrás?**
Sim, você pode selecionar qualquer data passada. A venda aparecerá nos relatórios daquele dia.

**Posso registrar uma gorjeta ou atribuir um garçom em uma venda manual?**
Não. Vendas manuais não suportam gorjeta nem atribuição de garçom. Para esses casos use o POS, que registra ambos os campos no checkout.
