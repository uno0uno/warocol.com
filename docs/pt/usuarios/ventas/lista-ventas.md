# Ver vendas

Em **Vendas** você pode consultar o histórico completo de pedidos, filtrá-los e exportá-los.

## Acessar

Menu lateral → **Vendas**

---

## Filtros disponíveis

| Filtro | Opções |
|--------|--------|
| Busca | Número do pedido, nome ou telefone do cliente |
| Período | Hoje · Ontem · Última semana · 15 dias · 30 dias · 90 dias |
| Método de pagamento | Selecione um grupo (ex.: Cartão) ou um método específico dentro do grupo (ex.: Visa). A lista é definida pelo administrador no POS. |
| Garçom | Filtra pelo garçom atribuído ao pedido |
| Canal | POS · Mesa · Online |
| Status | Concluída · Cancelada · Pendente |

---

## Informações por pedido

Cada linha mostra: número do pedido, data, cliente, quantidade de itens, método de pagamento, total e status. Se o pedido teve garçom atribuído ou gorjeta, essa informação aparece no detalhe.

- **Verde** — concluída
- **Amarelo** — pendente
- **Vermelho** — cancelada

---

## Exportar

Use o botão **Exportar** para receber o relatório no seu e-mail. O arquivo inclui todos os pedidos do período filtrado.

---

## Registrar venda manual

Se uma venda ocorreu fora do POS (pagamento antecipado, pedido por telefone, etc.), use **Registrar venda manual** para inseri-la manualmente. Veja [Registrar venda manual](./registrar-venta.md).

---

## Ver detalhe de um pedido

Clique em qualquer linha para ver o detalhamento completo: produtos, modificadores, cliente e total.

O detalhe também inclui, quando aplicável:
- **Garçom** atribuído ao pedido — clique para abrir o perfil
- **Gorjeta** cobrada — valor, tipo (percentual sugerido ou personalizado) e % sobre a venda
- Linha **Total cobrado** = subtotal + gorjeta (somente se houve gorjeta)

No detalhe você pode:
- **Imprimir venda** (recibo)
- **Editar** itens (remover produtos ou modificadores — o estoque é ajustado automaticamente)
