# Finanças

**Finanzas** agrupa o controle do dinheiro: fechamento de caixa, fechamento contábil, carteira a crédito, despesas, métodos de pagamento e relatórios contábeis.

## Como acessar

Menu lateral → **Finanzas**. Abas principais:

| Aba | Para quê |
|---------|----------|
| **Arqueo de caja** | Fechamento diário (Cierre Z) e prévia (Cierre X) |
| **Cierre contable** | Fechamento mensal irreversível |
| **Cartera** | Créditos de clientes pendentes |
| **Gastos** | Custos operacionais |
| **Métodos de pago** | Grupos e métodos no POS e nos relatórios |

Você também encontrará **Cuentas**, **Asientos**, **Balance** e **P&L Mensual** para a contabilidade do tenant.
