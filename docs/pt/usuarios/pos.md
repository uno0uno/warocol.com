# POS

O **POS** (ponto de venda) é onde você toma pedidos presenciais — balcão, mesa ou bar —, adiciona produtos ao carrinho e cobra.

## Como acessar

Menu lateral → **POS**.

- Se as mesas estiverem desativadas, você entra direto nos produtos.
- Se estiverem ativas, verá primeiro o mapa do salão.
