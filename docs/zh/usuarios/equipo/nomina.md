# 工资单和社会福利

在 **团队 → 工资单** 中，您可以管理 **哥伦比亚法定社会福利**（Prima、Cesantías、假期工资、工作装备、加班费）以及 **PILA**（社会保障）付款。

> **与薪资的区别：** **薪资** 标签页处理 **基本工资** 的月度付款。工资单是补充模块——处理 **法定福利** 和 **社会保障**，这些按不同频率支付（根据项目为半年、每年或每月）。请参阅 [记录工资付款](./registrar-pago)。

## 如何访问

侧边栏 → **团队 → 工资单**。

---

## 筛选

| 筛选 | 选项 |
|--------|----------|
| 年份 | 最近 5 年 |
| 月份 | 所选年份的特定月份 |
| 搜索 | 按员工姓名 |

---

## 福利表

每位员工一行，每个项目一列：

| 列 | 代表内容 |
|---------|----------------|
| **上半年奖金** | 上半年服务奖金（6 月支付） |
| **下半年奖金** | 下半年服务奖金（12 月支付） |
| **遣散费** | 员工遣散费的年度缴款 |
| **遣散费利息** | 遣散费利息（年 12%） |
| **假期工资** | 已休假期的付款 |
| **工作装备** | 每年三次付款（4 月、8 月、12 月），适用于工资 ≤ 2 SMMLV 的员工 |
| **加班费** | 该期间的加班费付款 |

每个单元格显示：

- **带金额的绿色徽章** — 该期间已支付该福利
- **"待处理"** — 尚未记录付款

### 合同类型

- **员工** — 适用于所有福利
- **日工** — 适用于除工作装备外的福利
- **承包商** — 不在此视图中（按酬金管理）

---

## 登记福利

您可以一次选择多个单元格：

- **点击单元格** — 选择该单项付款
- **点击行** — 选择该员工的所有福利
- **点击列** — 为所有员工选择该项目
- **混合批量选择** — 组合单个单元格

当有活动选择时，顶部会出现 **操作栏**，显示待登记总额和打开侧边付款面板的按钮。

### 侧边付款面板

| 字段 | 说明 |
|-------|-------------|
| 金额 | 默认为 WARO 计算值；您可以调整 |
| 付款日期 | 付款发生的日期 |
| 付款方式 | 转账、现金、支票等 |
| 参考 | 凭证编号（可选） |
| 备注 | 附加说明（可选） |

确认后，所有选定的福利都会登记为已付款，徽章变为绿色。

---

## PILA（Planilla Integrada de Liquidación de Aportes）

**PILA** 部分位于屏幕底部，单独显示。这是每月社会保障付款（医疗、养老、工伤、准财政），涵盖 **员工缴款** 和 **雇主缴款**。

### 待处理期间

列出有待支付社会保障的月份。每行显示：

- 月份和年份
- 应付总额（员工 + 雇主缴款）
- 包含的员工数量

### 登记 PILA 付款

1. 点击该行的 **登记 PILA** 按钮。
2. 输入日期和付款方式。
3. 如有 PILA 凭证，请附上。
4. 确认。

### PILA 历史

待处理列表下方显示已支付 PILA 的列表，包含日期、金额和方式。

## 常见问题

**WARO 会自动计算每项福利的金额吗？**
在大多数情况下会。平台使用员工配置的基本工资和哥伦比亚法定百分比来计算 Prima、Cesantías、利息、假期工资和工作装备。您始终可以在登记付款前手动调整金额。

**与记录工资付款有什么区别？**
**薪资** 中的"记录付款"是当前月工资的支付。**工资单** 用于法定福利和社会保障，频率和规则不同。

**如果我有承包商怎么办？**
承包商不在此视图中，因为他们不产生社会福利。其付款作为 **费用**（财务 → 费用）或按小时工资方案管理，视情况而定。

**我可以一次为多名员工支付福利吗？**
可以。选择列（例如"上半年奖金"），该项目的所有单元格都会被选中；付款面板会合并总金额。

**如何知道某个月的 PILA 是否已支付？**
如果在 **历史** 列表中而不在 **待处理** 中，则已登记。要查看凭证，请打开付款详情。
