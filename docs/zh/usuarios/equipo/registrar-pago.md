# 记录工资付款

## 为什么要在 WARO 中记录付款？

记录工资付款可以让您清楚地了解何时向每位员工支付了多少、对应哪个期间。您还可以附上凭证。

---

## 如何记录付款

前往 **团队 → 薪资**，找到该员工并点击其姓名。然后选择 **记录付款**。

### 付款信息

| 字段 | 填写内容 | 必填 |
|-------|-----------|:-----------:|
| 付款金额 | 哥伦比亚比索金额 | 是 |
| 付款日期 | 付款发生的日期 | 是 |
| 付款方式 | 现金、转账、支票或其他 | 是 |
| 参考 | 转账编号或银行凭证 | 否 |
| 期间 | 该工资对应的月份和年份 | 是 |

> 如果员工已配置工资，WARO 会显示该期间的参考金额。您可以将其作为基础或输入不同数值。

### 凭证

您可以附加文件（照片、PDF）作为付款凭证。如果付款是通过转账完成的，这有助于留存记录。

点击 **记录付款** 保存。

---

## 如何查看付款历史

前往 **团队 → 薪资** 并选择该员工。您将看到所有已记录付款的日期、金额和期间。

您也可以前往 **团队 → 薪资 → 付款**，在一个地方查看整个团队的所有付款。

---

## 常见问题

**我可以记录部分付款吗？**
可以。金额可自由填写，不必与配置的工资完全一致。请记录您实际支付的金额。

**我可以删除已记录的付款吗？**
请咨询管理员。付款是会计记录，通常不会删除，而是添加更正备注。

**员工会收到付款通知吗？**
不会自动通知。如需发送凭证，请附上并单独分享。

**WARO 会自动计算社会福利吗？**
系统会记录付款，但福利（Cesantías、假期等）的计算需要您或您的会计师完成。
