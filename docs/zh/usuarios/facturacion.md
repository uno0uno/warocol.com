# 开票

在 **开票** 中配置向 DIAN 开具有效电子发票所需内容：决议、税务数据、税费与技术服务商。

## 如何进入

侧边菜单 → **开票**。你会看到就绪横幅以及用于完成配置的卡片。

## 需要核对的内容

- **DIAN 决议** — 授权号段与有效期
- **税务数据** — 店铺身份
- **销售适用税费** — 在 WARO 护栏之下
- **技术服务商** — 电子开具
- **已用号码日志** — 连续号控制
