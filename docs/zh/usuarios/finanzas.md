# 财务

**财务** 集中资金控制：收银盘点、会计结账、赊账应收、支出、支付方式与会计报表。

## 如何进入

侧边菜单 → **财务**。主要标签页：

| 标签页 | 用途 |
|---------|----------|
| **收银盘点** | 每日对账（Cierre Z）与预览（Cierre X） |
| **会计结账** | 不可撤销的月度结账 |
| **应收** | 待收客户赊账 |
| **支出** | 运营成本 |
| **支付方式** | POS 与报表中的分组与方式 |

你还会找到 **账户**、**分录**、**资产负债表** 与 **月度损益表**，用于租户会计。
