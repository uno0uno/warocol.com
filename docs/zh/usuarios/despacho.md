# 配送

**配送** 集中管理在线订单、待确认的桌台 QR 订单队列，以及（如适用）厨房单据监控。

## 如何进入

侧边菜单 → **配送**。根据配置最多可见三个标签页：

| 标签页 | 用途 |
|---------|----------|
| **外卖** | 在线订单（外卖、自取、堂食消费） |
| **桌台订单（QR）** | 待接受或拒绝的 QR 订单 |
| **单据** | 厨房实时监控（若已启用单据） |
