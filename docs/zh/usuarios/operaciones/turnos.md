# 班次

**班次** 是可复用的排班模板（名称 + 开始和结束时间），在 **财务** 中进行 **按模板** 现金对账时使用。它们不替代人员排班或考勤：仅定义收银对账要核对的时间窗口。

## 如何访问

侧边栏 → **运营 → 班次**。

顶部显示活跃与停用班次数量。列表显示名称、排班和状态。

> **权限：** 配置班次需要 **运营** 模块访问权限。使用该模板登记对账在 **财务 → 现金对账**（**财务** 模块）中完成。见 [现金对账](../finanzas#arqueo-de-caja)。

---

## 创建班次

点击 **+ 新班次**。填写：

| 字段 | 说明 |
|------|------|
| **名称** | 可见标识（如上午、下午、夜班）。必填，最多 80 字符。 |
| **开始** | 班次开始时间（24 小时制）。 |
| **结束** | 班次结束时间。 |
| **跨越午夜** | 若班次次日结束请启用（如 22:00 – 06:00）。 |

用 **创建班次** 确认。班次立即 **启用** 并出现在按模板对账的下拉列表中。

---

## 编辑班次

点击班次旁的铅笔图标。可更改名称、时间和 **跨越午夜**。用 **保存更改** 保存。

**已登记** 的对账保留关闭时的名称标签；更改模板不会改写历史。

---

## 停用与重新启用

- **停用** — 创建新对账时不再显示该班次，但在列表中仍可见为停用。使用它的过往对账不会修改。
- **重新启用** — 再次在 财务 → 现金对账 → **按模板** 中可用。

界面不能删除班次；停用是弃用不再使用的模板的方式。

---

## 与现金对账的关系

| 操作 | 位置 |
|------|------|
| 定义模板（上午、下午…） | **运营 → 班次** |
| 用模板关账 | **财务 → 现金对账 → 按模板** |
| 无模板手动时间关账 | **财务 → 现金对账 → 自定义时间段** |
| 关闭整个日历日 | **财务 → 现金对账 → 全天** |

按模板对账时选择 **班次** 和 **日期**；时间按模板填充。同一天可多次对账，若时间窗口**不重叠**（例如上午和下午）。见 [现金对账](../finanzas#arqueo-de-caja) 中*同一天多次对账*一节。

## 常见问题 — 班次

**班次控制谁能在 POS 收款吗？**
不。它们仅定义现金对账的时间窗口。

**能否有两个相同时段的模板？**
可以，若名称不同（如「上午大厅」和「上午露台」）。对账时选择适用的模板。

**停用班次后对账里看不到了怎么办？**
在列表中用圆形箭头图标重新启用，或创建新模板。

**跨两天的夜班？**
创建或编辑模板时启用 **跨越午夜**（如 22:00 – 06:00）。
