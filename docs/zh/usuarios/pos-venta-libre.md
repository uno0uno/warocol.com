# 自由销售

**自由销售**允许收取菜单中未固定的比索金额（服务费、杂项费用）。收银员当场输入金额；不必为每笔销售新建产品。

> 仅当管理员在 **运营 → 个性化** 中启用后，该按钮才会出现在 POS 中。

## 如何进入

1. 在 **运营 → 个性化** 中启用 **POS 自由销售**。
2. 在 POS 中，使用购物车面板上的 **自由销售** 按钮。
3. 输入金额（必填），可选填写说明；然后按正常流程收款。
