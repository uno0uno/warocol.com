# 手动录入销售

当销售发生在 POS 之外时使用此选项：预付款、电话订单、事后登记的赠送等。

## 何时使用

- 客户在到店前已付款
- 销售在纸上处理，需要录入系统
- 需要登记过去日期的销售

---

## 步骤

### 1. 日期、支付方式和客户

- 选择销售发生的**日期**（不能是未来日期）
- 选择**支付方式**。列表使用为 POS 配置的方式
- 如果方式有子方式（例如 Nequi 或 Daviplata），在对应分组内选择
- 可选点击**识别客户**将销售关联到已注册客户

如果您识别了**COP 钱包**有余额的客户，钱包会显示为可用支付方式。如果销售保持匿名或客户无余额，则不显示该方式。

### 2. 添加商品

目录显示所有可用商品。

- 点击商品添加到购物车
- 如果商品有**附加项**，会出现侧边面板供选择
- 使用 **+** / **−** 按钮直接在购物车中调整数量

### 3. 确认

右侧面板（桌面）或底部摘要（手机）实时显示总额。

按**登记**保存。销售将以您选择的日期登记，如果商品配置了配方，库存会自动扣减。

---

## 常见问题

**会扣减库存吗？**
会，与 POS 相同。如果商品有配方，登记时会扣减仓库物品。

**可以不识别客户就登记销售吗？**
可以，手动销售中客户为可选项。

**可以使用几天前的日期吗？**
可以，您可以选择任何过去的日期。销售会出现在该日的报告中。

**可以在手动销售中登记小费或分配服务员吗？**
不可以。手动销售不支持小费或服务员归属。这些情况请使用 POS，它会在结账时登记这两个字段。
