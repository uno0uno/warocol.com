# 查看销售

在**销售**中，您可以查看完整的订单历史、筛选并导出。

## 访问

侧边栏 → **销售**

---

## 可用筛选

| 筛选 | 选项 |
|------|------|
| 搜索 | 订单号、客户姓名或电话 |
| 日期范围 | 今天 · 昨天 · 上周 · 15 天 · 30 天 · 90 天 |
| 支付方式 | 选择一个分组（例如：银行卡）或分组内的具体方式（例如：Visa）。列表由管理员在 POS 中定义。 |
| 服务员 | 按分配给订单的服务员筛选 |
| 渠道 | POS · 餐桌 · 线上 |
| 状态 | 已完成 · 已取消 · 待处理 |

---

## 每笔订单信息

每行显示：订单号、日期、客户、商品数量、支付方式、总额和状态。如果订单分配了服务员或有小费，该信息会显示在详情中。

- **绿色** — 已完成
- **黄色** — 待处理
- **红色** — 已取消

---

## 导出

使用**导出**按钮将报告发送到您的邮箱。文件包含筛选时间段内的所有订单。

---

## 手动录入销售

如果销售发生在 POS 之外（预付款、电话订单等），请使用**手动录入销售**手动录入。参见[手动录入销售](./registrar-venta.md)。

---

## 查看订单详情

点击任意行查看完整明细：商品、附加项、客户和总额。

详情还包括（如适用）：
- 分配给订单的**服务员** — 点击打开其个人资料
- 收取的**小费** — 金额、类型（建议百分比或自定义）及占销售额的 %
- **已收款总额**行 = 小计 + 小费（仅在有小费时显示）

在详情中您可以：
- **打印销售单**
- **编辑**商品（删除商品或附加项 — 库存会自动调整）
