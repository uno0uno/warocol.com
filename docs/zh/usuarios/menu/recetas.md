# 菜谱

## 什么是菜谱？

菜谱是**可重复使用的仓库商品组合**，可分配给一个或多个产品。避免在每个产品中重复填写相同的仓库商品列表。

**实用示例：** 您有一种自制酱汁用于 5 道不同的菜。与其在每个产品中添加相同的 6 个仓库商品，不如创建名为「自制酱汁」的菜谱并关联到这 5 个产品。修改菜谱后，变更会应用到所有使用它的产品。

顾客看不到菜谱。它们是内部用的：用于控制成本并自动从库存中扣减仓库商品。

---

## 何时使用菜谱？

菜谱是**可选的**。产品可以：

| 配置 | 何时使用 |
|------|----------|
| 仅直接仓库商品 | 产品简单且独特——没有其他菜品以相同组合使用这些仓库商品 |
| 仅菜谱 | 制备方式与其他产品共享 |
| 菜谱 + 额外仓库商品 | 有共同基础（菜谱）加上本菜品专属的仓库商品 |

> 如果产品独特且简单，直接添加仓库商品即可，无需创建菜谱。菜谱在**重复使用**时才有价值。

## 如何创建菜谱

前往 **菜单 → 菜谱 → 新建基本配方**。

表单分 3 步：

### 步骤 1 — 基本信息

| 字段 | 填写内容 |
|------|----------|
| 名称 | 菜谱的内部名称。例如 `自制酱汁`、`肉馅底料`、`披萨面团` |
| 状态 | 启用或禁用。若已在使用，请设为启用。 |

> 名称仅供内部使用。请描述制备方式，而非最终产品。

### 步骤 2 — 仓库商品

在此为每个仓库商品添加数量。

- 在搜索框中按名称查找仓库商品
- 输入数量和单位（克、毫升、件等）
- 对每个仓库商品重复操作

**若仓库商品不存在：** 搜索中会显示 **+ 创建库存商品**。点击可在侧边面板中创建，无需离开表单。

从此处创建时需填写：

| 字段 | 必填 | 说明 |
|------|:----:|------|
| 名称 | 是 | 例如 `特制安格斯牛肉` |
| 计量类型 | 是 | 重量（gr/kg）、体积（ml/lt）或件（und）。仅在创建时设定——之后不可更改。 |
| 分类 | 是 | 例如 `肉类`、`酱汁`、`乳制品` |

采购单位会根据计量类型自动生成。保存后，该仓库商品即可在菜谱中选择。

→ [了解更多自有仓库商品](https://warocol.com/docs/usuarios/compras#artículos de bodega-propios)

### 步骤 3 — 审核与确认

查看摘要：名称、仓库商品数量和状态。确认无误后，点击 **创建配方**。

---

## 之后可以编辑菜谱吗？

可以。前往 **菜单 → 菜谱**，找到菜谱并点击编辑。变更会应用于之后使用它的所有产品——已记录的订单不受影响。

---

## 常见问题

**创建产品是否必须有菜谱？**
不是。可以直接用仓库商品创建产品，无需任何菜谱。

**一个产品可以有多个菜谱吗？**
可以。可为同一产品分配多个菜谱，还可在这些菜谱之外添加额外仓库商品。

**可以有两个同名菜谱吗？**
系统允许，但不建议。请使用描述性名称以免混淆。

**如果更改菜谱中的仓库商品会怎样？**
变更会从此应用于所有使用该菜谱的产品。已记录的销售不会更改。
