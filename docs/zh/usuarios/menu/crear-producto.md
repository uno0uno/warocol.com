# 创建产品

## 什么是产品？

产品是顾客看到并可以点的内容：有名称、价格、描述和分类。它显示在您的菜单上。

**示例：** 玛格丽特披萨、经典汉堡、天然柠檬水。

---

## 产品组成如何工作

每个产品可通过三种方式分配仓库商品——可单独使用或组合：

| 选项 | 何时使用 |
|------|----------|
| **仅直接仓库商品** | 产品独特，不与其他菜品共享制备方式 |
| **仅菜谱** | 制备方式是已在多个产品中使用的菜谱 |
| **菜谱 + 额外仓库商品** | 有共同基础（菜谱）加上本菜品专属仓库商品 |

> 向导中选择 **按配方制作**：销售时 WARO 按菜谱扣减库存。
>
> **直接销售**（转售）：按件（`und`）销售；系统创建库存项及 gr 或 ml 换算。

**何时先创建菜谱？** 仅当该制备在多个产品中复用时。若菜品独特，直接向产品添加仓库商品。→ [菜谱指南](./recetas.md)

---

## 如何创建产品

前往 **菜单 → 产品 → 新产品**。

选择 **按配方制作** 时向导有 **4 步**，选择 **直接销售** 时为 **3 步**（无菜谱步骤）。

### 产品税费

若企业使用 **商业税**（开票中的税行），产品 **继承** **菜单分类** 的税费。可保持默认、标为 **免税** 或选择 **其他税行**。该覆盖优先于分类映射。

在哥伦比亚列式税务矩阵下，仍选择食品/饮料、酒类或免税。

### 步骤 1 — 产品类型

选择如何制备或销售：

| 选项 | 含义 |
|------|------|
| **按配方制作** | 厨房 · 仓库商品和基础配方；每次销售扣减库存 |
| **直接销售** | 转售 · 按件（`und`），gr 或 ml 换算 |

### 步骤 2 — 基本信息

| 字段 | 填写内容 | 必填 |
|------|----------|:----:|
| 产品名称 | 顾客看到的名称。例如 `玛格丽特披萨` | 是 |
| 描述 | 菜品简短描述 | 否 |
| 分类 | 所属分组（开胃菜、主菜、饮料...） | 是 |
| 销售价格 | 哥伦比亚比索价格 | 是 |
| 准备时间 | 分钟数（仅 **按配方制作**） | 否 |
| gr/ml 换算 | 每售出单位的重量或体积（仅 **直接销售**） | 是 |
| 可用 | 是否在菜单中启用 | — |
| 可用于外卖 | 是否出现在在线订单（外卖/自取） | — |
| 餐桌点餐 (QR) | 是否出现在餐桌 QR 菜单 | — |

> 关闭 **可用** 后，产品不会出现在任何菜单，直到再次启用。
>
> **餐桌点餐 (QR)** 与外卖独立。

### 步骤 3 — 菜谱（仅按配方制作）

在此定义产品组成：

**添加菜谱** — 点击 **+ 添加基础配方** 并搜索已有菜谱。

**添加直接仓库商品** — 逐个添加仓库商品及数量。

**若仓库商品不存在：** 搜索中显示 **+ 创建库存商品**（侧边面板，无需离开表单）。

→ [了解更多自有仓库商品](https://warocol.com/docs/usuarios/compras#artículos de bodega-propios)

创建时可留空菜谱和仓库商品，之后可补全，但定义菜谱后成本和库存扣减更准确。

### 步骤 4 — 审核与确认

查看摘要：名称、分类、菜谱或转售数据及状态。确认无误后点击 **创建产品**。

---

## 产品会立即出现在在线菜单吗？

会，只要勾选 **可用于外卖**。未勾选时产品存在于系统中，但在线顾客看不到。

---

## 常见问题

**之后可以改价格吗？**
可以。前往 **菜单 → 产品**，打开产品并编辑。

**不分配菜谱或仓库商品（按配方制作）会怎样？**
产品仍可销售，但 WARO 无法计算成本或自动扣减库存，直到定义菜谱。

**同一产品可以分配多个菜谱吗？**
可以。可组合多个菜谱并添加额外仓库商品。

**如何添加附加项（尺寸、加料、酱汁）？**
附加项单独创建并分配给一个或多个产品。见 [附加项指南](./modificadores.md)。

**如何为产品添加照片？**
在基本信息步骤，或创建后在编辑界面。
