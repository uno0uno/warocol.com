# 附加项

## 什么是附加项？

附加项是顾客点产品时可选的额外选项。选项分组在 **附加项分组** 中。

**示例：**
- 分组「尺寸」→ 选项：小份、中份、大份
- 分组「酱汁」→ 选项：BBQ、粉红酱、辣味
- 分组「不要...」→ 选项：不要洋葱、不要番茄、不要生菜
- 分组「加料」→ 选项：多加芝士（+$2,000）、培根（+$3,000）

每个分组分配给一个或多个产品。顾客点该产品时会看到分组选项以自定义订单。

---

## 开始前的关键概念

**分组：** 选项类别的名称（例如「尺寸」）。

**附加项：** 分组内的每个选项（例如「小份」「中份」「大份」）。可有加价或免费。

**必选与可选：** 必选分组下顾客必须至少选一项；可选可跳过。

**最少与最多选择：** 顾客可选/必选的数量。
- 最少 0，最多 1 → 可选一项或不选
- 最少 1，最多 1 → 必须选恰好一项
- 最少 0，最多 3 → 最多选 3 项（如加料）

## 如何创建附加项分组

前往 **菜单 → 附加项 → 新分组**。

表单分 3 步：

### 步骤 1 — 分组信息

| 字段 | 填写内容 | 必填 |
|------|----------|:----:|
| 产品 | 适用此分组的产品 | 是 |
| 分组名称 | 顾客看到的名称。例如 `尺寸`、`加料`、`酱汁` | 是 |
| 最少选择 | 顾客至少须选几项 | 是 |
| 最多选择 | 顾客最多可选几项 | 是 |
| 显示顺序 | 多个分组时谁先显示（数字越小越靠前） | 否 |
| 必选 | 顾客下单前是否必须选择 | — |

> **提示：** 尺寸分组须选一项时，设最少 1、最多 1，并标为必选。

### 步骤 2 — 分组选项（附加项）

在此添加每个可用选项。每项定义：

| 字段 | 填写内容 |
|------|----------|
| **类型** | 销售时如何扣库存（见下表） |
| 名称 | 选项名称。例如 `大份`、`BBQ`、`多加芝士` |
| 附加价格 | 在基础价上加多少。免费填 0。 |
| 最大 / 顺序 | 每行最大数量及屏幕顺序 |

点击 **+ 添加附加项** 添加更多选项。

#### 选项类型（组成与库存）

| 界面类型 | 何时使用 | 配置内容 | 销售时库存 |
|----------|----------|----------|------------|
| **仓库商品** | 目录中的原料，无关联菜单产品（原材料、耗材、服务） | 仓库商品 + 数量 + 单位；也可 **按分类批量添加** | 该商品 × 附加项数量 × 产品数量 |
| **转售** | 转售产品（与仓库商品 1:1 关联） | 转售产品 + 数量 + 单位 | 扣减产品关联的仓库商品 |
| **基础配方** | 按已有制备的多种原料 | 基础配方 + 倍数（数量 × 配方） | 扣减配方中 **全部** 商品，按倍数缩放 |
| **菜单产品** | 选项消耗另一菜单产品的组成（有配方菜品，非转售） | 菜单产品 + 倍数 | 扣减该产品配方/组成（如一份） |
| **仅价格** | 不影响仓库的附加（如包装、服务、「不要冰」） | 仅名称和价格 | **不** 动库存；只加销售总额 |

> **转售与仓库商品：** 都通过 **仓库商品** 扣库存。转售选 **菜单产品**，WARO 解析关联商品（1 und）。仓库商品直接从目录选。

搜索不到仓库商品时，在侧边面板用 **+ 创建库存商品**（名称、计量类型和分类必填）。

→ [了解更多自有仓库商品](/docs/usuarios/abastecimiento#catálogo-de-bodega)

### 步骤 3 — 审核

查看摘要并点击 **创建组**。

## 附加项何时加价？

顾客选择有附加价格的选项时，该金额自动加到产品价格在结账时（含 POS、餐桌和在线订单）。

---

## 销售时的库存与成本

- 附加项的 **销售价格** 始终保存在订单中。
- **仓库扣减** 取决于选项 **类型**：仓库商品、转售、基础配方或菜单产品按组成扣减；**仅价格** 不扣减。
- 编辑销售并 **删除** 附加项时，WARO 将已扣的原料退回库存。
- food cost / 会计结账使用每个附加项展开的原料明细。

## 常见问题

**一个分组可分配给多个产品吗？**
可以。创建分组时选择所有需要的产品。

**创建后可编辑选项吗？**
可以。前往 **菜单 → 附加项**，打开分组编辑。

**步骤 2 未添加任何选项？**
分组为空创建。稍后在编辑中添加。

**顾客可不选必选附加项下单吗？**
不可以。必选分组下须选择后「加入购物车」才可用。

**同一分组可混合类型吗？**
可以。例如尺寸用 **仅价格**，加料用 **仓库商品** 或 **转售**，套餐用 **基础配方**。

**顾客会选择选项类型吗？**
不会。类型仅在后台配置；收银台顾客只见名称和价格。
