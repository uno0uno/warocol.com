# 团队

在 **团队** 中管理谁有权限、以何种角色、薪资、付款与社保福利。

## 如何进入

侧边菜单 → **团队**。标签页：

- **成员** — 权限、角色与服务员资料
- **薪资** — 配置薪资与常规付款
- **工资单** — 福利（Prima、Cesantías 等）与 PILA
