# 采购供应

在 **采购供应** 中管理进入库存的内容：供应商、采购（AI 或正式）、库存、调整、库房目录与数据质量。

## 如何进入

侧边菜单 → **采购供应**。主要标签页：

| 标签页 | 用途 |
|---------|----------|
| **供应商** | 名录与付款协议 |
| **直接采购** | 用 AI 扫描器登记已付发票 |
| **库存** | 水平、KPI 与告警 |
| **调整** | 库存手动更正 |
| **库房目录** | 餐厅自有物料 |

你还会看到 **数据质量**；正式采购单与供应商付款通过上下文操作打开。
