# 用户指南

欢迎查阅 WARO 文档。这里有你日常经营餐厅所需的一切。

文档结构与侧边菜单一致：入门指南，然后是主要、工具、账户与 Dev。

---

## 入门指南

- [入门指南](./usuarios/primeros-pasos) — 登录与建议的起步顺序

## 主要

| 模块 | 你可以做什么 |
|--------|------------------|
| [POS](./usuarios/pos) | 在销售点处理销售（柜台、桌台、吧台）；包括[自由销售](./usuarios/pos-venta-libre) |
| [销售](./usuarios/ventas) | 订单历史、已售产品与小费 |
| [配送](./usuarios/despacho) | 在线订单（外卖与自取）及厨房单据 |

## 工具

| 模块 | 你可以做什么 |
|--------|------------------|
| [销售分析](./usuarios/analitica) | 销售、盈利、客户与积分看板 |
| [财务](./usuarios/finanzas) | 盘点、会计结账、应收、支出、支付方式与会计 |
| [开票](./usuarios/facturacion) | DIAN 电子发票、决议、税务数据 |
| [菜单](./usuarios/menu) | 配方、产品、修饰项与分类 |
| [运营](./usuarios/operaciones) | 单据与厨房、桌台、个性化与小费 |
| [采购供应](./usuarios/abastecimiento) | 供应商、采购、库存、调整、自有原料与数据质量 |
| [团队](./usuarios/equipo) | 成员、薪资、工资单与服务员资料 |

## 账户

| 模块 | 你可以做什么 |
