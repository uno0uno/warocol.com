# Freier Verkauf

**Venta libre** erlaubt das Kassieren eines Pesos-Betrags, der nicht im Menü hinterlegt ist (Dienstleistungen, sonstige Gebühren). Die Kasse gibt den Betrag im Moment ein; ein neues Produkt pro Verkauf ist nicht nötig.

> Der Button erscheint im POS nur, wenn ein Administrator ihn unter **Operaciones → Personalizar** aktiviert.

## So gelangen Sie dorthin

1. Aktivieren Sie **Venta libre en POS** unter **Operaciones → Personalizar**.
2. Nutzen Sie im POS den Button **Venta libre** im Warenkorb-Panel.
3. Geben Sie den Betrag (Pflicht) und optional eine Beschreibung ein; kassieren Sie danach im normalen Ablauf.
