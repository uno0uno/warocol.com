# Analytik

**Analítica** zeigt in Zahlen, wie der Betrieb läuft: Verkäufe, meistgefragte Produkte, Kunden und Rentabilität.

## So gelangen Sie dorthin

Seitenmenü → **Analítica Ventas**. Sie landen in der Ansicht **Ventas**; von dort aus gelangen Sie auch zu:

- **Rentabilidad** — Margen je Produkt
- **Clientes** — Häufigkeit und Verhalten
- **Puntos** — Punkteprogramm (Waros)
