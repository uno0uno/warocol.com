# Mein Betrieb

Unter **Mi Negocio** steuern Sie das öffentliche Profil des Restaurants: wie Sie bei WARO erscheinen, Kontakt, Öffnungszeiten und Online-Bestellungen.

## So gelangen Sie dorthin

Seitenmenü → **Cuenta → Mi Negocio**. Nutzen Sie **Editar perfil** zum Ändern und **Guardar** zum Speichern.

## Was Sie konfigurieren können

- Öffentliches Profil (Name, Beschreibung, Logo, Banner)
- Sichtbarkeit im Verzeichnis und öffentlicher Link
- Kontakt, Öffnungszeiten und soziale Netzwerke
- Online-Bestellungen (Lieferung / Abholung)
