# POS

Das **POS** (Point of Sale) ist der Ort, an dem Sie Bestellungen vor Ort aufnehmen — Theke, Tisch oder Bar —, Produkte in den Warenkorb legen und kassieren.

## So gelangen Sie dorthin

Seitenmenü → **POS**.

- Sind Tische deaktiviert, gelangen Sie direkt zu den Produkten.
- Sind sie aktiv, sehen Sie zuerst den Saalplan.
