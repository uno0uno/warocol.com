# Finanzen

**Finanzas** bündelt die Geldkontrolle: Kassenabschluss, Buchungsabschluss, Forderungen auf Kredit, Ausgaben, Zahlungsarten und Buchhaltungsberichte.

## So gelangen Sie dorthin

Seitenmenü → **Finanzas**. Wichtige Registerkarten:

| Registerkarte | Wofür |
|---------|----------|
| **Arqueo de caja** | Täglicher Abschluss (Cierre Z) und Vorschau (Cierre X) |
| **Cierre contable** | Unumkehrbarer Monatsabschluss |
| **Cartera** | Offene Kundenkredite |
| **Gastos** | Betriebskosten |
| **Métodos de pago** | Gruppen und Methoden in POS und Berichten |

Außerdem finden Sie **Cuentas**, **Asientos**, **Balance** und **P&L Mensual** für die Buchhaltung des Tenants.
