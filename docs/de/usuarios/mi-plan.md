# Mein Plan

Unter **Mi Plan** verwalten Sie Ihr WARO-Abo: aktueller Plan, Zahlungen, Historie und KI-Nutzung.

## So gelangen Sie dorthin

Seitenmenü → **Cuenta → Mi Plan**. Registerkarten:

| Registerkarte | Wofür |
|---------|----------|
| **Historial** | Aktueller Plan, Abo, Zahlungen und Ereignisse |
| **Uso de IA** | Monatlicher Verbrauch von KI-Scans |
