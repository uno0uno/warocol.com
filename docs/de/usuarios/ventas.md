# Verkäufe

Unter **Ventas** prüfen Sie die Bestellhistorie, filtern und exportieren und können Verkäufe außerhalb des POS erfassen.

## So gelangen Sie dorthin

Seitenmenü → **Ventas**. Registerkarten:

- **Órdenes** — allgemeine Historie (Standardansicht)
- **Productos** — was verkauft wurde und in welcher Menge
- **Propinas** — Trinkgeldhistorie (die Konfiguration liegt unter Betrieb)
