# المالية

تجمع **المالية** التحكم في المال: جرد الصندوق، الإقفال المحاسبي، الذمم بالائتمان، المصروفات، طرق الدفع والتقارير المحاسبية.

## كيفية الوصول

القائمة الجانبية → **المالية**. التبويبات الرئيسية:

| التبويب | الغرض |
|---------|----------|
| **جرد الصندوق** | المطابقة اليومية (Cierre Z) والمعاينة (Cierre X) |
| **الإقفال المحاسبي** | إقفال شهري لا رجعة فيه |
| **الذمم** | ائتمانات العملاء المعلقة |
| **المصروفات** | التكاليف التشغيلية |
| **طرق الدفع** | المجموعات والطرق في POS والتقارير |

ستجد أيضًا **الحسابات** و**القيود** و**الميزانية** و**قائمة الدخل الشهرية** لمحاسبة المستأجر.

## التالي

- عرض الطلبات والتحصيلات: [المبيعات](./ventas)
- ضبط الإكراميات (وليس السجل): [العمليات](./operaciones)
- الفوترة الإلكترونية DIAN: [الفوترة](./facturacion)
- بدء اليوم عند الصندوق: [POS](./pos)
