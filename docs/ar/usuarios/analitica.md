# التحليلات

تعرض **التحليلات** بالأرقام كيف يسير النشاط: المبيعات والمنتجات الأكثر طلبًا والعملاء والربحية.

## كيفية الوصول

القائمة الجانبية → **تحليلات المبيعات**. تدخل إلى عرض **المبيعات**؛ ومن هناك يمكنك أيضًا الذهاب إلى:

- **الربحية** — الهوامش حسب المنتج
- **العملاء** — التكرار والسلوك
- **النقاط** — برنامج النقاط (Waros)
