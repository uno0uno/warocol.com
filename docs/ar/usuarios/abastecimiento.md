# التوريد

من **التوريد** تدير ما يدخل المخزون: الموردون، المشتريات (بالذكاء الاصطناعي أو الرسمية)، المخزون، التعديلات، كتالوج المخزن وجودة البيانات.

## كيفية الوصول

القائمة الجانبية → **التوريد**. التبويبات الرئيسية:

| التبويب | الغرض |
|---------|----------|
| **الموردون** | الدليل واتفاقيات الدفع |
| **شراء مباشر** | فواتير مدفوعة بماسح الذكاء الاصطناعي |
| **المخزون** | المستويات ومؤشرات الأداء والتنبيهات |
| **التعديلات** | تصحيحات يدوية للمخزون |
| **كتالوج المخزن** | أصناف المطعم الخاصة |

سترى أيضًا **جودة البيانات**؛ أوامر الشراء الرسمية ومدفوعات الموردين تُفتح من إجراءات سياقية.
