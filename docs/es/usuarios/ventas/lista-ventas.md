# Ver ventas

Desde **Ventas** puedes consultar el historial completo de órdenes, filtrarlas y exportarlas.

## Acceder

Menú lateral → **Ventas**

---

## Filtros disponibles

| Filtro | Opciones |
|--------|----------|
| Búsqueda | Número de orden, nombre o teléfono del cliente |
| Rango de fechas | Hoy · Ayer · Última semana · 15 días · 30 días · 90 días |
| Método de pago | Selecciona un grupo (ej: Tarjeta) o un método específico dentro del grupo (ej: Visa). La lista la define el administrador en POS. |
| Mesero | Filtra por el mesero asignado a la orden |
| Canal | POS · Mesa · Online |
| Estado | Completada · Cancelada · Pendiente |

---

## Información por orden

Cada fila muestra: número de orden, fecha, cliente, cantidad de ítems, método de pago, total y estado. Si la orden tuvo mesero asignado o propina, esa información aparece en el detalle.

- **Verde** — completada
- **Amarillo** — pendiente
- **Rojo** — cancelada

---

## Exportar

Usa el botón **Exportar** para recibir el reporte en tu correo. El archivo incluye todas las órdenes del período filtrado.

---

## Registrar venta manual

Si una venta ocurrió fuera del POS (pago adelantado, pedido por teléfono, etc.), usa **Registrar venta** para ingresarla manualmente. Ver [Registrar venta manual](./registrar-venta.md).

---

## Ver detalle de una orden

Haz clic en cualquier fila para ver el desglose completo: productos, modificadores, cliente y total.

El detalle también incluye, cuando aplica:
- **Mesero** asignado a la orden — clic para abrir su perfil
- **Propina** cobrada — monto, tipo (porcentaje sugerido o personalizada) y % sobre la venta
- Línea **Total cobrado** = subtotal + propina (solo si hubo propina)

Desde el detalle puedes:
- **Imprimir** el recibo
- **Editar** ítems (eliminar productos o modificadores — el inventario se ajusta automáticamente)
