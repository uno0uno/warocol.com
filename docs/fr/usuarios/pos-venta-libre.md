# Vente libre

**Venta libre** permet d'encaisser un montant en pesos qui n'est pas fixé dans le menu (services, frais divers). Le caissier saisit le montant au moment de la vente ; inutile de créer un nouveau produit à chaque fois.

> Le bouton n'apparaît dans le POS que si un administrateur l'active dans **Operaciones → Personalizar**.

## Comment y accéder

1. Activez **Venta libre en POS** dans **Operaciones → Personalizar**.
2. Dans le POS, utilisez le bouton **Venta libre** dans le panneau du panier.
3. Saisissez le montant (obligatoire) et, si vous voulez, une description ; puis encaissez avec le flux normal.
