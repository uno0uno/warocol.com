# POS

Le **POS** (point de vente) est l'endroit où vous prenez les commandes en salle — comptoir, table ou bar —, ajoutez des produits au panier et encaissez.

## Comment y accéder

Menu latéral → **POS**.

- Si les tables sont désactivées, vous arrivez directement sur les produits.
- Si elles sont actives, vous voyez d'abord le plan de salle.
