# Opérations

**Operaciones** configure le quotidien du restaurant : cuisine, tables, audit du POS, shifts, personnalisation, promotions et pourboires.

## Comment y accéder

Menu latéral → **Operaciones**.

## Suite

- [Tables](./operaciones/mesas) — plan de salle, sessions et QR
- [Bitácora](./operaciones/bitacora) — audit des actions dans le POS
- [Shifts](./operaciones/turnos) — modèles pour les clôtures par horaire
- Historique des pourboires (après configuration ici) : [Pourboires](./ventas/propinas)
- Encaisser en caisse : [POS](./pos)
