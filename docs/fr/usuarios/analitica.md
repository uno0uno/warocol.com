# Analytique

**Analítica** montre en chiffres comment va l'établissement : ventes, produits les plus demandés, clients et rentabilité.

## Comment y accéder

Menu latéral → **Analítica Ventas**. Vous arrivez sur la vue **Ventas** ; depuis là, vous pouvez aussi aller vers :

- **Rentabilidad** — marges par produit
- **Clientes** — fréquence et comportement
- **Puntos** — programme de points (Waros)

## Suite

- Historique opérationnel des commandes : [Ventes](./ventas)
- Contrôle de l'argent du jour : [Finances](./finanzas)
- Commencer à vendre : [POS](./pos)
