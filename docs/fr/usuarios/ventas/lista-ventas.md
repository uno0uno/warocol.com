# Voir les ventes

Depuis **Ventes**, vous pouvez consulter l'historique complet des commandes, les filtrer et les exporter.

## Accéder

Menu latéral → **Ventes**

---

## Filtres disponibles

| Filtre | Options |
|--------|---------|
| Recherche | Numéro de commande, nom ou téléphone du client |
| Plage de dates | Aujourd'hui · Hier · Dernière semaine · 15 jours · 30 jours · 90 jours |
| Mode de paiement | Sélectionnez un groupe (ex. : Carte) ou un mode spécifique dans le groupe (ex. : Visa). La liste est définie par l'administrateur dans le POS. |
| Serveur | Filtre par le serveur attribué à la commande |
| Canal | POS · Table · Online |
| Statut | Terminée · Annulée · En attente |

---

## Informations par commande

Chaque ligne affiche : numéro de commande, date, client, nombre d'articles, mode de paiement, total et statut. Si la commande avait un serveur attribué ou un pourboire, ces informations apparaissent dans le détail.

- **Vert** — terminée
- **Jaune** — en attente
- **Rouge** — annulée

---

## Exporter

Utilisez le bouton **Exporter** pour recevoir le rapport par e-mail. Le fichier inclut toutes les commandes de la période filtrée.

---

## Enregistrer une vente manuelle

Si une vente a eu lieu en dehors du POS (paiement anticipé, commande par téléphone, etc.), utilisez **Enregistrer une vente manuelle** pour la saisir manuellement. Voir [Enregistrer une vente manuelle](./registrar-venta.md).

---

## Voir le détail d'une commande

Cliquez sur n'importe quelle ligne pour voir le détail complet : produits, modificateurs, client et total.

Le détail inclut également, le cas échéant :
- **Serveur** attribué à la commande — cliquez pour ouvrir son profil
- **Pourboire** encaissé — montant, type (pourcentage suggéré ou personnalisé) et % sur la vente
- Ligne **Total encaissé** = sous-total + pourboire (uniquement s'il y a eu un pourboire)

Depuis le détail, vous pouvez :
- **Imprimer la vente** (reçu)
- **Modifier** les articles (supprimer des produits ou modificateurs — le stock est ajusté automatiquement)
