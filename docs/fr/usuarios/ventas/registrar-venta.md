# Enregistrer une vente manuelle

Utilisez cette option lorsqu'une vente a eu lieu en dehors du POS : paiement anticipé, commande par téléphone, courtoisie enregistrée après coup, etc.

## Quand l'utiliser

- Le client a payé avant d'arriver sur place
- La vente a été traitée sur papier et doit être saisie dans le système
- Vous devez enregistrer une vente à une date passée

---

## Étapes

### 1. Date, mode de paiement et client

- Sélectionnez la **date** à laquelle la vente a eu lieu (ne peut pas être une date future)
- Choisissez le **mode de paiement**. La liste utilise les modes configurés pour le POS
- Si le mode a des sous-modes (par exemple Nequi ou Daviplata), sélectionnez-le dans le groupe correspondant
- Optionnellement, appuyez sur **Identifier le client** pour associer la vente à un client enregistré

Si vous identifiez un client avec un solde dans le **portefeuille COP**, le portefeuille apparaît comme mode de paiement disponible. Si la vente reste anonyme ou le client n'a pas de solde, ce mode n'est pas affiché.

### 2. Ajouter des produits

Le catalogue affiche tous vos produits disponibles.

- Appuyez sur un produit pour l'ajouter au panier
- Si le produit a des **Modificateurs**, un panneau latéral apparaît pour les sélectionner
- Utilisez les boutons **+** / **−** pour ajuster les quantités directement dans le panier

### 3. Confirmer

Le panneau de droite (bureau) ou le résumé inférieur (mobile) affiche le total en temps réel.

Appuyez sur **Enregistrer** pour enregistrer. La vente sera enregistrée avec la date que vous avez choisie et le stock est déduit automatiquement si les produits ont des recettes configurées.

---

## Questions fréquentes

**Le stock est-il déduit ?**
Oui, comme au POS. Si le produit a une recette, les articles d'entrepôt sont déduits lors de l'enregistrement.

**Puis-je enregistrer une vente sans identifier le client ?**
Oui, le client est optionnel pour les ventes manuelles.

**Puis-je utiliser une date d'il y a plusieurs jours ?**
Oui, vous pouvez sélectionner n'importe quelle date passée. La vente apparaîtra dans les rapports de ce jour-là.

**Puis-je enregistrer un pourboire ou attribuer un serveur sur une vente manuelle ?**
Non. Les ventes manuelles ne prennent pas en charge les pourboires ni l'attribution de serveur. Pour ces cas, utilisez le POS, qui enregistre les deux champs au paiement.
