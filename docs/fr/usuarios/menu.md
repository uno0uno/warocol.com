# Menu

Depuis **Menú**, vous configurez ce que vous proposez aux clients : recettes de base, produits du menu et modificateurs (tailles, extras, sauces).

## Comment y accéder

Menu latéral → **Menú**.

## Suite

- [Recettes](./menu/recetas) — compositions réutilisables d'articles de stock
- [Produits](./menu/productos) — ce qui apparaît dans le POS et en livraison
- [Créer un produit](./menu/crear-producto) — création pas à pas
- [Modificateurs](./menu/modificadores) — options pour personnaliser les produits

> Avant de vendre, le menu est l'étape critique : sans produits, vous ne pouvez pas utiliser le POS ni les commandes en ligne.
