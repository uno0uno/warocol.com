# Finanzas

**Finanzas** agrupa el control del dinero: arqueo de caja, cierre contable, cartera a crédito, gastos, métodos de pago y reportes contables.

## Cómo acceder

Menú lateral → **Finanzas**. Pestañas principales:

| Pestaña | Para qué |
|---------|----------|
| **Arqueo de caja** | Cuadre diario (Cierre Z) y vista previa (Cierre X) |
| **Cierre contable** | Cierre mensual irreversible |
| **Cartera** | Créditos de clientes pendientes |
| **Gastos** | Costos operativos |
| **Métodos de pago** | Grupos y métodos en POS y reportes |

También encontrarás **Cuentas**, **Asientos**, **Balance** y **P&L Mensual** para la contabilidad del tenant.
