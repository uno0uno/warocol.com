# Facturación

Desde **Facturación** configuras lo necesario para emitir facturas electrónicas válidas ante la DIAN: resolución, datos fiscales, impuestos y proveedor técnico.

## Cómo acceder

Menú lateral → **Facturación**. Verás un banner de readiness y tarjetas para completar la configuración.

## Qué revisar

- **Resolución DIAN** — rango autorizado y vigencia
- **Datos fiscales** — identidad del negocio
- **Impuestos aplicados a ventas** — bajo el guardrail de WARO
- **Proveedor técnico** — emisión electrónica
- **Bitácora de números quemados** — control de consecutivos
