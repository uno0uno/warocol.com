# Equipo

Desde **Equipo** gestionas quién tiene acceso, con qué rol, salarios, pagos y prestaciones sociales.

## Cómo acceder

Menú lateral → **Equipo**. Pestañas:

- **Miembros** — accesos, roles y perfil de meseros
- **Salarios** — configurar salario y pagos corrientes
- **Nómina** — prestaciones (Prima, Cesantías, etc.) y PILA
