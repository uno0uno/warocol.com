# POS

El **POS** (punto de venta) es donde tomas pedidos presenciales — mostrador, mesa o barra — agregas productos al carrito y cobras.

## Cómo acceder

Menú lateral → **POS**.

- Si las mesas están desactivadas, entras directo a productos.
- Si están activas, verás primero el plano del salón.
