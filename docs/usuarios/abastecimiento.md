# Abastecimiento

Desde **Abastecimiento** gestionas lo que entra al inventario: proveedores, compras (con IA o formales), stock, ajustes, catálogo de bodega y calidad de datos.

## Cómo acceder

Menú lateral → **Abastecimiento**. Pestañas principales:

| Pestaña | Para qué |
|---------|----------|
| **Proveedores** | Directorio y acuerdos de pago |
| **Compra Directa** | Facturas pagadas con escáner de IA |
| **Stock** | Niveles, KPIs y alertas |
| **Ajustes** | Correcciones manuales de inventario |
| **Catálogo de bodega** | Artículos propios del restaurante |

También verás **Calidad de Datos**; órdenes de compra formales y pagos a proveedores se abren desde acciones contextuales.
