# View sales

From **Sales** you can view the full order history, filter orders, and export them.

## Access

Sidebar → **Sales**

---

## Available filters

| Filter | Options |
|--------|---------|
| Search | Order number, customer name, or phone |
| Date range | Today · Yesterday · Last week · 15 days · 30 days · 90 days |
| Payment method | Select a group (e.g. Card) or a specific method within the group (e.g. Visa). The list is defined by the administrator in POS. |
| Waiter | Filter by the waiter assigned to the order |
| Channel | POS · Table · Online |
| Status | Completed · Cancelled · Pending |

---

## Information per order

Each row shows: order number, date, customer, item count, payment method, total, and status. If the order had an assigned waiter or tip, that information appears in the detail.

- **Green** — completed
- **Yellow** — pending
- **Red** — cancelled

---

## Export

Use the **Export** button to receive the report in your email. The file includes all orders in the filtered period.

---

## Record manual sale

If a sale happened outside the POS (advance payment, phone order, etc.), use **Record manual sale** to enter it manually. See [Record manual sale](./registrar-venta.md).

---

## View order detail

Click any row to see the full breakdown: products, modifiers, customer, and total.

The detail also includes, when applicable:
- **Waiter** assigned to the order — click to open their profile
- **Tip** collected — amount, type (suggested percentage or custom), and % of the sale
- **Total charged** line = subtotal + tip (only if there was a tip)

From the detail you can:
- **Print sale**
- **Edit** items (remove products or modifiers — inventory is adjusted automatically)
