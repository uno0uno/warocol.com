# Open sale

**Open sale** lets you charge an amount in pesos that isn’t fixed on the menu (services, miscellaneous charges). The cashier enters the value at the time of sale; you don’t need to create a new product for each sale.

> The button only appears in POS if an administrator enables it in **Operations → Customize**.

## How to access

1. Enable **Open sale in POS** in **Operations → Customize**.
2. In POS, use the **Open sale** button in the cart panel.
3. Enter the amount (required) and, optionally, a description; then collect payment with the normal flow.
