# उपयोगकर्ता गाइड

WARO दस्तावेज़ीकरण में आपका स्वागत है। यहाँ आपको अपने रेस्तरां को रोज़ चलाने के लिए आवश्यक सब कुछ मिलेगा।

दस्तावेज़ीकरण साइड मेनू की संरचना को दोहराता है: पहले कदम, फिर मुख्य, उपकरण, खाता और Dev।

## पहले कदम

- [पहले कदम](./usuarios/primeros-pasos) — लॉगिन और शुरू करने का सुझाया क्रम

## मुख्य

| मॉड्यूल | आप क्या कर सकते हैं |
|--------|------------------|
| [POS](./usuarios/pos) | पॉइंट ऑफ़ सेल पर बिक्री (काउंटर, टेबल, बार); इसमें [मुक्त बिक्री](./usuarios/pos-venta-libre) शामिल है |
| [बिक्री](./usuarios/ventas) | ऑर्डर इतिहास, बिके उत्पाद और टिप्स |
| [डिस्पैच](./usuarios/despacho) | ऑनलाइन ऑर्डर (डिलीवरी और पिकअप) और रसोई टिकट |

| [बिलिंग](./usuarios/facturacion) | DIAN इलेक्ट्रॉनिक इनवॉइसिंग, रिज़ॉल्यूशन, कर डेटा |
