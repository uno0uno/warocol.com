# वित्त

**वित्त** नकद नियंत्रण को एक जगह लाता है: कैश काउंट, लेखांकन बंद, क्रेडिट प्राप्य, खर्च, भुगतान विधियाँ और लेखांकन रिपोर्ट।

## कैसे पहुँचें

साइड मेनू → **वित्त**। मुख्य टैब:

| टैब | किस लिए |
|---------|----------|
| **कैश काउंट** | दैनिक मिलान (Cierre Z) और पूर्वावलोकन (Cierre X) |
| **लेखांकन बंद** | अपरिवर्तनीय मासिक बंद |
| **प्राप्य** | लंबित ग्राहक क्रेडिट |
| **खर्च** | परिचालन लागत |
| **भुगतान विधियाँ** | POS और रिपोर्ट में समूह और विधियाँ |

आप टेनेंट लेखांकन के लिए **खाते**, **प्रविष्टियाँ**, **बैलेंस** और **मासिक P&L** भी पाएँगे।
