# मेरा व्यवसाय

**मेरा व्यवसाय** से आप रेस्तरां की सार्वजनिक प्रोफ़ाइल नियंत्रित करते हैं: WARO पर कैसे दिखते हैं, संपर्क, समयसारिणी और ऑनलाइन ऑर्डर।

## कैसे पहुँचें

साइड मेनू → **खाता → मेरा व्यवसाय**। बदलने के लिए **Editar perfil** और लागू करने के लिए **Guardar** उपयोग करें।

## आप क्या कॉन्फ़िगर कर सकते हैं

- सार्वजनिक प्रोफ़ाइल (नाम, विवरण, लोगो, बैनर)
- निर्देशिका में दृश्यता और सार्वजनिक लिंक
- संपर्क, समयसारिणी और सोशल नेटवर्क
- ऑनलाइन ऑर्डर (डिलीवरी / पिकअप)
