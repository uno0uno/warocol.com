# बिक्री

**बिक्री** से आप ऑर्डर इतिहास देख सकते हैं, फ़िल्टर और निर्यात कर सकते हैं, और POS के बाहर हुई बिक्री दर्ज कर सकते हैं।

## कैसे पहुँचें

साइड मेनू → **बिक्री**। टैब:

- **ऑर्डर** — सामान्य इतिहास (डिफ़ॉल्ट दृश्य)
- **उत्पाद** — क्या और कितनी मात्रा में बिका
- **टिप्स** — टिप इतिहास (सेटिंग संचालन में रहती है)
