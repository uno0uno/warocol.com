# मेनू

**मेनू** से आप वह कॉन्फ़िगर करते हैं जो ग्राहकों को देते हैं: आधार रेसिपी, मेनू उत्पाद और संशोधक (आकार, अतिरिक्त, सॉस)।

## कैसे पहुँचें

साइड मेनू → **मेनू**।

## आगे

- [रेसिपी](./menu/recetas) — भंडार वस्तुओं की पुन: उपयोग योग्य संरचनाएँ
- [उत्पाद](./menu/productos) — POS और डिलीवरी में क्या दिखता है
- [उत्पाद बनाएँ](./menu/crear-producto) — चरण-दर-चरण निर्माण
- [संशोधक](./menu/modificadores) — उत्पादों को अनुकूलित करने के विकल्प

> बेचने से पहले मेनू महत्वपूर्ण चरण है: बिना उत्पादों के आप POS या ऑनलाइन ऑर्डर नहीं चला सकते।
