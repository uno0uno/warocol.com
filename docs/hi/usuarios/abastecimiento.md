# आपूर्ति

**आपूर्ति** से आप इन्वेंटरी में आने वाली चीज़ें प्रबंधित करते हैं: आपूर्तिकर्ता, खरीद (AI या औपचारिक), स्टॉक, समायोजन, भंडार कैटलॉग और डेटा गुणवत्ता।

## कैसे पहुँचें

साइड मेनू → **आपूर्ति**। मुख्य टैब:

| टैब | किस लिए |
|---------|----------|
| **आपूर्तिकर्ता** | निर्देशिका और भुगतान समझौते |
| **सीधी खरीद** | AI स्कैनर से भुगतान किए गए इनवॉइस |
| **स्टॉक** | स्तर, KPI और अलर्ट |
| **समायोजन** | इन्वेंटरी के मैन्युअल सुधार |
| **भंडार कैटलॉग** | रेस्तरां की स्वयं की वस्तुएँ |

आप **डेटा गुणवत्ता** भी देखेंगे; औपचारिक खरीद आदेश और आपूर्तिकर्ता भुगतान संदर्भ क्रियाओं से खुलते हैं।
