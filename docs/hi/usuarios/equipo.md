# टीम

**टीम** से आप प्रबंधित करते हैं कि किसे पहुँच है, किस भूमिका से, वेतन, भुगतान और सामाजिक लाभ।

## कैसे पहुँचें

साइड मेनू → **टीम**। टैब:

- **सदस्य** — पहुँच, भूमिकाएँ और वेटर प्रोफ़ाइल
- **वेतन** — वेतन और नियमित भुगतान कॉन्फ़िगर करें
- **पेरोल** — लाभ (Prima, Cesantías, आदि) और PILA
